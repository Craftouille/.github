# Craftouille

**Craftouille** est un **serveur Minecraft francophone orienté Mini-Jeux** offrant une expérience conviviale et originale pour les joueurs Java (versions **1.21 à 26.2**).
- Mode **Bingo** avec des mécaniques inédites
- **Freebuild**
- **Lavarise**
- ItemsCollection
- Événements communautaires

📍 Serveur : `play.craftouille.fr`
